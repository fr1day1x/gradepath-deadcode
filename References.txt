and submission documentation. Generated changes were checked using automated
tests and browser workflows. AI assistance is disclosed rather than attributed
to a human teammate's commit history.

VISUAL REFERENCES
The BMO-inspired companion is based on Adventure Time and a calculator-character
reference image supplied by the team. It is implemented with local Three.js
geometry; no official character model was downloaded. Character/reference rights
belong to their respective owners. A team-provided animation reference video
informed the interface motion. Its original creator was not identified in the
provided material. The team should supplement this file with any sources or tools
used outside this development conversation.
